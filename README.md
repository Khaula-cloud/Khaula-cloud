## 01 — About

I'm a Cloud Engineer focused on building and understanding reliable infrastructure.

My journey started in MERN development and gradually moved toward cloud computing, automation, and infrastructure engineering.

I enjoy working on problems that go beyond getting an application running:

- How do we make infrastructure reproducible?
- What happens when an application receives more traffic?
- How do we secure communication between services?
- How can deployments become predictable instead of manual?
- How do we monitor systems before users notice something is wrong?

I learn by building real systems, testing their limits, troubleshooting failures, and documenting the engineering decisions behind them.

## 05 — Engineering Principles

**Understand before automating.**  
I want to know why a system works before making it repeatable.

**Design for failure.**  
Infrastructure should account for what happens when individual components stop working.

**Make systems observable.**  
Monitoring and logs should help explain what is happening, not just show that something failed.

**Document engineering decisions.**  
A good project explains not only what was built, but why particular approaches were chosen.
